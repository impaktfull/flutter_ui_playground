# 0.0.2

## Added

- `UiPlaygroundComponentConfig` class for configuring external widgets from packages you cannot annotate
- `customInputs` parameter on `@UiPlaygroundComponent` for per-component custom input classes
- `extraComponents` parameter on `@UiPlaygroundComponents` for including external widgets
- `extraComponentsOnly` parameter on `@UiPlaygroundComponents` to only use explicit components
- `customInputs` parameter on `@UiPlaygroundComponents` for global custom input classes
